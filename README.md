📖 О проекте
Учебный проект к занятию «WebWorkers, ServiceWorkers». Реализован интерфейс загрузки с отказоустойчивым поведением: страница открывается даже без сети, а при невозможности загрузить данные показывается экран ошибки вместо «белого экрана».

✨ Ключевые возможности
Скелетон-загрузка — пока данные не получены, отображаются серые блоки-заглушки, повторяющие структуру контента.

Офлайн-режим — Service Worker кэширует статические ресурсы (HTML, CSS, JS, картинки), поэтому страница открывается без интернета.

Обработка ошибок — если API недоступен, через ~1.2 сек показывается понятный экран «Не удалось загрузить данные / Проверьте подключение / и обновите страницу».

Эмуляция задержки — на бэкенде используется koa-slow, чтобы скелетон был виден даже при быстром соединении.
